# 简历素材 — 大模型开发工程师向

> 侧重点：模型侧能力（RAG、Agent 设计、Function Calling、Prompt 工程、评估）。

## 项目：科研智能体 Research Agent（2026.07–08）

**一句话**：设计并实现基于 ReAct 范式的科研 Agent，以 DeepSeek function calling 编排 RAG 知识库、论文参数抽取、仿真建模与科学计算工具链，打通"论文→参数→头模仿真→定量验证"闭环，具备记忆沉淀与调用级评估能力。

- **Agent 编排设计**：实现 Recall→Ground→Plan→Act→Observe→Reflect→Distill 的科研 ReAct 循环，LLM 经 OpenAI 兼容 function calling 驱动 6+ 工具；设计 ToolDescriptor 元数据（成本提示/依赖声明/异步能力），使模型规划时可感知工具代价与可用性。
- **论文→仿真参数桥**：arXiv 工具链 + 论文理解子代理（agent-as-tool），LLM 抽取仿真参数并以"schema 校验 + 原文引句 + 失败局部重试"三道闸防编造，引句滑窗匹配适配 PDF 断词等真实噪声。
- **仿真合成底盘**：设计 BackendTask→CompilerRegistry 架构，论文参数经编译器映射为 Sim4Life 建模/求解脚本（figure8 线圈/三层头模/材料数据库链接全自动生成），B2 已验证路径逐字节回归保护。
- **RAG 知识接入与防幻觉**：接入自建 Sim4Life 手册 RAG 服务（Dense+BM25 混合检索 + Cross-Encoder 重排 + UI 真值库绑定 + 反证校验），为 Agent 的建模/仿真决策提供可追溯依据；失败路径明确报错，杜绝静默降级产生的幻觉。
- **评估与实证文化**：建立多级 ground truth（基准复算 max 相对差 0.000%、体素计数与几何体积定量吻合、场型特征判定），Agent 产出全部以结构化断言闭环验证；30 次工具调用成功率实测 100%。
- **记忆与评估**：实现 wiki 知识库工具（frontmatter 结构化记录 + 关键词检索），验证跨会话记忆召回（新会话召回 5 条历史记录）；实现 after_tool 追踪钩子，沉淀 30 次真实调用数据（成功率 100%），形成可量化的 Agent 行为评估依据。

**技术栈**：LLM Function Calling、ReAct、Prompt Engineering、Agentic RAG、Hybrid Retrieval、Reranker、DeepSeek（OpenAI 兼容）、SSE、知识记忆/Wiki、实验追踪与评估、仿真验证（h5py 定量对比）。
