# 面试问答预案（STAR 式）

## Q1: 这个科研 Agent 是干什么的？你负责哪部分？

**S**: 科研场景里，仿真建模、文献调研、参数优化分散在多个软件和流程里，手动串联低效。
**T**: 做一个能理解科研问题、自动调用工具完成"查资料→优化→建模→记录"闭环的 Agent。
**A**: 我独立设计并实现了整个系统：ReAct 编排循环、6 个工具的 Function Calling 接入、ToolDescriptor 元数据框架、wiki 记忆层和 experiment tracking。
**R**: 端到端 demo 一次跑通，工具调用成功率实测 100%（30/30），跨会话记忆可召回。

## Q2: 最有挑战的技术问题是什么？

**S**: 需要 Agent 自动驱动 Sim4Life 建模，但它是有 FlexNet 许可的商业 GUI 软件。
**T**: 实现无界面（headless）建模执行。
**A**: 裸调 API 时触发 FlexNet 许可弹窗卡死。我系统排查：确认许可在可信存储中 GUI 可用 → 定位 `lmgrd` 服务与 `SPEAG_LICENSE_FILE` 机制 → 阅读 `s4l_v1` 源码发现 `run_application()` 上下文引导入口 → 验证建模仿真保存全链路。
**R**: headless 建模仿真稳定可用（实测 3/3，平均 15.3s），并沉淀为可复用的 `s4l_run_script` 工具。

## Q3: 怎么保证 Agent 不胡说八道（防幻觉）？

**S**: LLM 可能编造不存在的 API 或仿真结果。
**T**: 多层次防幻觉。
**A**: ① RAG 知识库给决策提供手册依据（混合检索+重排+真值库+反证校验）；② 提示词内置最小可用模板与"不存在 API 不要编造"的硬约束；③ 故障路径明确报错而非静默降级（RAG 宕机直接报错，不瞎编）；④ experiment tracking 记录每次调用，可审计。
**R**: 消除了模型编造 `document.CurrentDocument()` 的幻觉；鲁棒性测试 6/6 验证故障路径行为。

## Q4: 怎么评估你的 Agent 好不好用？

**S**: Agent 类项目常见问题是"能跑但不知道多可靠"。
**T**: 建立可量化的行为评估。
**A**: 实现 after_tool 追踪钩子，每次工具调用的参数/结果/耗时/成败落 JSONL；写统计脚本生成成功率与耗时分布；多场景（问答/优化/全链路）重复运行统计端到端成功率。
**R**: 实测 30 次工具调用 100% 成功；数据还帮我定位出 LLM 长连接挂起的外部问题——证明了追踪体系的价值。

## Q5: 工具是怎么设计和扩展的？

**S**: 工具数量会增长，不能每加一个就改编排。
**T**: 设计可扩展的工具框架。
**A**: 定义 ToolDescriptor 元数据层（category/cost_hint/requires/async_capable/produces_artifacts），工具按目录组织、注册即生效，`requires` 支持启动时依赖自检（如 RAG 服务没起就明确报错）；预留执行钩子链与异步任务抽象。
**R**: 6 个工具统一接入，新增工具只需丢一个文件，编排层零改动；启动自检在实测中正确识别了未启动的 RAG 服务。

## Q6: 记忆功能怎么做的？

**S**: 一次性对话的 Agent 没有积累，科研需要连续记忆。
**T**: 让研究结论可跨会话检索。
**A**: 实现 wiki 工具：每次研究结束把"问题-方案-结果-结论"写成带 frontmatter（标题/时间/标签）的 markdown，git 管理；wiki_search 支持关键词召回。
**R**: 新会话成功召回 5 条历史记录；wiki 本身也是可读的实验档案。

## Q7: 遇到过 Agent 不按要求来/跑偏吗？怎么处理？

**S**: 开放式任务中，LLM 可能重复调用、编造参数或无限循环。
**T**: 让执行路径可控可收敛。
**A**: ① 收紧任务描述为编号步骤并标注"每步一次调用"；② 修正工具 schema 与 handler 的参数契约一致性（曾因 schema 无必填但 handler 必填导致 TypeError）；③ 调整轮次上限与 LLM 超时/重试参数；④ 鲁棒性测试锁定行为。
**R**: demo 从"跑飞/超时"变为稳定一次通过（EXIT=0）。

## Q8: 这个项目和你简历里其他项目是什么关系？

**S**: 避免项目看起来是孤立的 demo 堆砌。
**T**: 形成一条完整的能力线。
**A**: 四个仓库各司其职：litmusAgent 是我自研的 Agent 引擎（678 测试）；Sim4Life-RAG-Helper 是手册知识库（混合检索+反幻觉，37 测试）；StreamFunctionTMS 是科学计算工具（405 测试含 MATLAB 数值回归）；research-agent 把它们作为工具编排成科研智能体。
**R**: 简历主线 = "自研框架驱动的科研智能体，覆盖知识检索、仿真建模、科学计算与记忆沉淀"，总测试 1100+。
