## Research Agent — LLM-driven Scientific Research Agent (Jul–Aug 2026, ongoing)

**One-liner**: Built a ReAct-style research agent on a self-developed agent framework and DeepSeek, orchestrating 15 tools across literature search (arXiv/PDF), paper-to-parameter extraction, Sim4Life headless simulation modeling, scientific solving, TMS coil optimization, and wiki memory — closing the loop "paper → simulation parameters → head-model lossy solve → quantitative field validation", with experiment tracking and cross-session knowledge memory.

- **Agent orchestration design**: Implemented a Recall→Ground→Plan→Act→Observe→Reflect→Distill research ReAct loop; the LLM drives 15 tools via OpenAI-compatible Function Calling. Designed a `ToolDescriptor` metadata layer (cost hints / dependency declarations / async capability / artifact declarations) so the model can reason about tool cost and availability at planning time, with startup dependency checks and zero orchestration changes for new tools.
- **Paper → simulation-parameter bridge**: Built an arXiv literature toolchain plus a paper-understanding sub-agent (agent-as-tool); LLM-extracted simulation parameters are guarded by three anti-hallucination gates — schema validation, verbatim quote matching from the source PDF (sliding-window match tolerant of PDF line-break noise), and localized retry on failure.
- **Reverse-engineered license unlock for headless commercial simulation**: Diagnosed Sim4Life student edition as cloud-session licensing (only the GUI process holds the QS solver license) over 15 rounds of investigation, disproving 3 bypass schemes by experiment; discovered the official `Sim4LifeLight.exe --minimized --run` entry point so scripts inherit the license inside the GUI process, enabling fully unattended lossy solving and result extraction (h5py direct read of Output.h5, bypassing the post-processing API).
- **Quantitative verification with multi-level ground truth**: Established benchmark recomputation (E-field three-component max relative diff 0.000% over ~790k strong-field voxels per component — pipeline-level exact reproduction), voxel-count vs. geometric-volume checks (brain 273k / skull 78k / scalp 64k, matching theoretical volumes), and field-shape sanity checks (focal E/I = 1.93e-2 V/m/A @3kHz, 5kA-equivalent ≈96 V/m, right at TMS stimulation threshold magnitude); grid convergence verified at 4.60% focal-depth E diff (1mm vs 2mm, <5% criterion); MQS eddy-current solve converged in 6 iterations, 420s full GUI --run cycle.
- **Deep debugging & root-cause methodology**: Resolved a blocking head-model voxelization failure through 37 rounds of controlled single-variable probes (known-good-model A/B control → injection experiments → component-binding diff → unit audit), isolating three stacked root causes (mesh not bound to entities / default voxel engine incompatible with scripted entities / document defaulting to millimeters making geometry 1000× too small); 70+ rounds of license/API/voxelization investigation distilled into a 40-item pitfall knowledge base. Over 3 hypothesis–experiment cycles, attributed an API defect (stimulus write not taking effect) to a read-only GUI session settings layer, routing around it via Input.h5 and explicitly documenting the boundary — no faked verification.
- **Evaluation & memory**: Built an evaluation harness with a tiered test suite (162 collected / 157 non-smoke green, covering contracts, emitter content assertions, synthetic fixtures, and byte-level regression guards, plus graded headless voxelization smoke ~25s and GUI solve smoke); after_tool tracking hook logs every tool call (args/result/duration/success) to JSONL — measured 100% success over 30 real calls; wiki memory tool verified for cross-session recall.
