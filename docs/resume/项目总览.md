# Research Agent — 项目总览（简历素材）

## 一句话定位

科研智能体：以自研 Agent 框架为引擎，通过 ReAct 循环驱动 Sim4Life 手册 RAG 知识库、Sim4Life headless 仿真建模、TMS 流函数线圈优化与联网检索，并把研究结论自动沉淀为可跨会话检索的个人 wiki 知识库。

## 架构图

```mermaid
flowchart TD
    U[科研问题] --> A[ReAct 循环<br/>litmusAgent 引擎 + DeepSeek<br/>Recall→Ground→Plan→Act→Observe→Reflect→Distill]
    A --> T1[web_search<br/>Tavily 文献检索]
    A --> T2[sim4life_manual_qa<br/>Sim4Life 手册 RAG<br/>混合检索+Reranker+反幻觉校验]
    A --> T3[s4l_write_script / s4l_run_script<br/>Sim4Life headless 建模/仿真]
    A --> T4[tms_optimize<br/>TMS 流函数优化 NSGA2]
    A --> T5[wiki_write / wiki_search<br/>个人知识库·跨会话记忆]
    T5 -.检索回流.-> A
    A --> TK[experiment tracking<br/>工具调用全程留痕 JSONL]
```
