# Sim4Life 实心球建模 + TMS 线圈优化 — 迷你流水线记录

## 任务目标
验证从 **Sim4Life 手册查询 → 脚本建模 → 文件保存 → 知识沉淀** 的完整闭环。

## 步骤与结果

### 1. 手册查询
- **工具**: `sim4life_manual_qa`
- **问题**: Sim4Life 中创建实心球模型的步骤
- **结果**: 手册无直接球体教程，但通过类比 `CreateSolidTube` 确认 API 为 `model.CreateSolidSphere(center=Vec3, radius=float)`。
- **UI 方式**: Model → Primitives → Sphere → 设置中心/半径。

### 2. TMS 线圈优化（默认参数）
- **工具**: `tms_optimize`
- **参数**: 默认（NSGA2，单椭圆 M1 模板）
- **结果**: 1.69s 完成，输出 4 个 Pareto 解；最佳目标值约 −276.6（电场聚焦度），对应 OA90 外区域面积 ≈34.2 cm²。

### 3. 脚本建模与执行
- **脚本**（`create_sphere.py`）：
  ```python
  import s4l_v1.model as model
  import s4l_v1.document as document
  document.New()
  sphere = model.CreateSolidSphere(model.Vec3(0,0,0), 10.0)
  sphere.Name = "demo_sphere"
  document.SaveAs(r"D:/myvibeproject/research-agent/artifacts/demo_sphere.smash")
  ```
- **执行**: Sim4Life Light 7.0.0.7995 headless 模式，8.56s 完成。
- **产物**: `artifacts/demo_sphere.smash` ✓

### 4. 结论与可复用要点
| 组件 | 关键要点 |
|------|----------|
| 手册查询 | 先查手册再写脚本，避免 API 用法错误 |
| TMS 优化 | 小规模（单椭圆）1.7s 可出 4 个 Pareto 解，适合快速探索 |
| 脚本建模 | 遵循 `document.New()` → 创建实体 → `document.SaveAs()` 模板 |
| 知识沉淀 | wiki_write 记录问题-方案-结果，便于后续复用 |
